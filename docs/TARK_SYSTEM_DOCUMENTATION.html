TARK (तर्क) V0.0.1

Adaptive, Board-Grounded Multi-Agent AI Tutor System

1. Executive Summary & Core Philosophy

"The model is the engine; the pedagogy and correctness are the product."

Tark (derived from the Sanskrit tarka, meaning logic and reasoning) is a multi-agent teaching platform. It eliminates the flaws of generic chatbot tutors through mathematical verification via SymPy, official board curriculum grounding (RAG), dynamic code-rendered visual diagrams, adaptive student learner tracking, and recursive self-improvement loops.

🎯 1. Teaches Correctly

SymPy-backed symbolic and numerical verification. The LLM never computes arithmetic or algebraic results unaided.

🎓 2. Teaches Pedagogically

Scaffolding, misconception detection, progressive hints, and Socratic guardrails that prevent answer-dumping.

🧠 3. Adapts & Improves

Bayesian-style mastery modeling per student and recursive self-improvement (RSI) triggered by student feedback.

2. Multi-Agent Orchestration & Intelligence Layer

Tark coordinates specialized autonomous agents on every turn to ensure high pedagogical quality:

🧭 Planner Agent

Analyzes student intent (explain, simpler, example, quiz, doubt), detects greetings vs academic questions, and determines whether to wake the Solver, Retriever, or heavy reasoning models.

📚 Retriever Agent (RAG)

Curriculum grounding across 930+ textbook chunks using local fastembed vectors (BAAI/bge-small-en-v1.5). Features smart query expansion into formal textbook terminology when confidence is low.

📐 Solver Agent (SymPy)

Executes symbolic algebra, root finding, and calculus steps prior to explanation generation. Verifies all post-generation arithmetic to prevent calculation hallucinations.

📊 Diagram Agent

Eliminates flawed image generation by rendering accurate code-based figures: Matplotlib function plots, Mermaid process cycles, and sanitized structural SVGs.

🔍 Checker & Cross-Check Agent

Compares tutor explanations against grounded textbook source passages using an independent model (Llama 3.3 70B) to ensure zero contradiction.

🔄 Improver Agent (RSI)

On negative student feedback (👎), the tutor critiques its own answer, extracts actionable teaching directives, and consolidates memory for future turns on that topic.

4. Pedagogy & Teaching Modes

👩‍🏫 Teacher / Lecture Mode

Structured 4-stage instructional design: Contextual introduction → Core concept breakdown → Step-by-step worked example → Formative comprehension check.

🏛️ Socratic Tutor Mode

Strict guardrail against answer-dumping: Guides the student through sequential questions, provides tiered hints on repeated struggle, and enables self-discovery.

5. Frontend & UI Capabilities

  • Real-time Streaming & KaTeX Rendering: Live token streaming via Server-Sent Events (SSE) with KaTeX math formatting.
  • Multimodal Homework Vision: Upload photos of worksheets, diagrams, or textbook questions for instant diagnosis.
  • Audio Read-Aloud (TTS): Natural voice playback powered by Gemini Flash TTS with Web Speech API fallback.
  • Conversation Management: Full sidebar history with automatic title generation, search, and session deletion.
  • Guest Quota & Gating: 20 free interactions for guest visitors before prompting account registration.
  • Student Progress Modal: Real-time mastery visualizer displaying mastered chapters, weak spots, and revision topics.
  • User Authentication: Email verification via Brevo with 6-digit OTP codes, password reset, and school-to-board autocomplete.
  • Appearance Modes: System default, Light, and Dark themes with full CSS tokenization.
