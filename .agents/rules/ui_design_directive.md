# Global UI Design Directive (Persistent)

You are responsible for maintaining and improving the entire application's UI/UX throughout all future changes.

## Permanent Design Rules

1. **Minimize Emoji Usage**
   * Remove decorative emojis from buttons, cards, headers, navigation items, alerts, badges, forms, dashboards, and marketing sections.
   * Only use emojis when they provide genuine meaning or improve accessibility.
   * Never use emojis as visual decoration.

2. **Avoid "AI-Vibe" Design**
   * Eliminate elements that make the product feel AI-generated or template-based.
   * Avoid excessive gradients, glowing borders, floating icons, oversized shadows, random illustrations, and generic AI-style graphics.
   * Replace flashy effects with clean, professional visual hierarchy.

3. **Professional Product Aesthetic**
   * Design should feel like a mature SaaS product rather than a hackathon prototype.
   * Prioritize clarity, consistency, spacing, typography, and usability.
   * Use icons only when they serve a functional purpose.

4. **Content & Copy**
   * Remove emoji-heavy text from notifications, onboarding screens, banners, tooltips, success messages, and empty states.
   * Rewrite copy to sound professional, trustworthy, and human.
   * Avoid phrases that sound AI-generated, overenthusiastic, or excessively promotional.

5. **Future Development Rule**
   * Every new screen, component, modal, dashboard, page, feature, notification, or redesign must automatically follow these guidelines.
   * Before completing any task, review the affected UI and remove any unnecessary emoji or AI-styled visual clutter.
   * Treat this as a permanent project constraint unless explicitly overridden.

## Design Goal
The application should feel:
* Professional
* Modern
* Clean
* Trustworthy
* Enterprise-ready
* Human-designed
and should never resemble an "AI-generated" or "vibe-coded" application.
